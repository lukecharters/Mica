# Mica

Mica is a macOS app for admins to create or extract icons with an accompanying command-line tool.

## Start here

- [The Mica Window](The-Mica-Window) identifies each part of the app.
- [Generation Modes](Generation-Modes) helps you choose Mica mode or System mode.
